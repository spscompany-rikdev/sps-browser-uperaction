# ───────────── SPS Browser - install everything needed to RUN and BUILD it ─────────────
#   python -m pip install -r requirements.txt
# Then build:   python tools/ci_build.py        (Windows / Linux / macOS)
#
# Python 3.12 or 3.13, 64-bit.  (Qt 6 WebEngine does not exist for 32-bit Windows/Linux.)
-r requirements-build.txt        # Qt + Chromium engine, psutil, watchdog, requests, certifi, PyInstaller  (required)
-r requirements-optional.txt     # text-to-speech "Read aloud" on Windows                                  (optional)
# Local AI is big (about 100 MB of wheels) so it is separate - add it with:
#   python -m pip install -r requirements-ai.txt
#
# SPS VPN needs NO Python library.  Its two free helper programs (wireproxy for WireGuard, Tor) are downloaded
# into <SPS_Browser folder>/vpn/ automatically by tools/ci_build.py (tools/fetch_vpn_components.py).
