# SPS Shield - Chrome / Edge / Brave / Opera extension

## Use it for free right now (no store, no fee)
1. Download `SPS_Shield_Extension_v….zip` from the GitHub Release and unzip it.
2. Open `chrome://extensions`, switch **Developer mode** on, click **Load unpacked**, choose the unzipped folder.
3. Pin the shield icon. Click it for: pause on this site, print a selected area, reader view, dark mode.
   Shortcut: Ctrl+Shift+P = print selected area.
(Edge: `edge://extensions`, Brave: `brave://extensions` - same steps.)

## Publish in the Chrome Web Store (optional)
- Needs a Google developer account (one-time US$5 fee set by Google - not by us).
- Upload the same zip, add screenshots, paste `PRIVACY_POLICY.md` as the privacy policy, explain each permission (see the policy).
- Google reviews it before it goes live. Edge Add-ons is free to publish.

## Why an extension?
Google Chrome's own source cannot be rebuilt here, and sign-in with Google is refused in embedded browsers. The extension gives real Chrome/Edge users the same privacy tools, and Google sign-in works there because it is the real Chrome.
